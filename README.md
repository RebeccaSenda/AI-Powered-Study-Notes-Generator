# AI-Powered Study Notes Generator

## Project Overview

The AI-Powered Study Notes Generator is a Generative AI application designed to help students create study notes from lecture materials.

Users will be able to upload lecture slides or PDF documents, and the system will process the material and generate concise study notes, key points, summaries, and exam-relevant information.

## Objectives

- Upload lecture slides or PDF documents
- Extract and process educational content
- Generate concise study notes using Generative AI
- Produce key points and summaries
- Provide a downloadable study guide

## AI Topic

Text Generation & Summarization
